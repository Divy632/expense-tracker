# 💰 Expense Tracker

A full-stack MERN Expense Tracker application that helps users manage their income and expenses efficiently.

## 🚀 Features

- User Authentication (JWT)
- Add Income
- Add Expenses
- Dashboard with Summary
- Transaction History
- MongoDB Database
- Responsive UI

## 🛠 Tech Stack

### Frontend
- React.js
- Vite
- CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

## 📂 Project Structure

```
expense-tracker/
│── backend/
│── frontend/
```

## ⚙️ Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
